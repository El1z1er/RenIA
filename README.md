# RenIA

## Objetivo

RenIA é um assistente inteligente para geração de programas de medição utilizando bibliotecas de rotinas de inspeção.

O usuário descreve, em linguagem natural, o que deseja medir e como deseja executar a inspeção.

O RenIA interpreta o pedido, seleciona as rotinas adequadas, organiza a lógica do programa e gera automaticamente um programa CNC completo.

Ao final, o usuário pode visualizar, copiar ou exportar o programa no formato de arquivo desejado.

## Filosofia

O RenIA não substitui as bibliotecas de medição existentes.

Seu objetivo é atuar como um assistente inteligente, simplificando a criação de programas de medição e reduzindo o tempo de desenvolvimento através da linguagem natural.
